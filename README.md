# Inventory System

A complete inventory system for FiveM with ESX Legacy.

## Features

- Manage player inventories
- Add default items
- Display inventory contents

## Requirements

- FiveM server
- ESX Legacy framework
- MySQL database

## Installation

1. Download the script
2. Place the script in your FiveM resources folder
3. Add `start inventory-system` to your server.cfg
4. Import the database.sql file into your MySQL database

## Usage

- Use the `/inventory` command to open your inventory

## Configuration

- `Config.MaxWeight`: Set the maximum weight for the inventory in grams
- `Config.DefaultItems`: Set the default items for new players
- `Config.Database.TableName`: Set the name of the database table for inventory items
